# Pokémon Card Price Bot (WhatsApp)

Bot WhatsApp personale: invii la foto di una carta Pokémon, il bot la riconosce e risponde con i prezzi
per le lingue che scegli (ita, eng, jap, …). Su richiesta traccia la carta e ti avvisa quando il prezzo cambia.

> Stato: in sviluppo. Il vecchio bot Telegram di notizie è stato rimosso.
> Setup completo (Meta/WhatsApp, variabili d'ambiente, deploy) in arrivo con l'MVP.
